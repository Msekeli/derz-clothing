# DERZ Ecosystem

## Master Architecture & Development Documentation

**Status:** Locked Foundation

## 1. Purpose

This document is the highest-level architectural source of truth for the DERZ software ecosystem.

It defines how the independent DERZ applications relate to one another, what each application owns, how they communicate, what they share, and where their boundaries exist.

The ecosystem currently consists of:

```text
DERZ Ecosystem
│
├── AuthService
├── DERZ Storefront
└── DERZ Admin
```
